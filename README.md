# بيئة التعلم الإلكتروني – رسالة دكتوراه، جامعة الزقازيق

## التشغيل
`python3 -m http.server 8000` ثم افتح http://localhost:8000 (لا حاجة لبناء أو تثبيت).

## الهيكل
- `index/content/mindmap/guide/contact.html` الصفحات الرئيسية، و`module-1..8.html` صفحات الموديولات، و`researcher.html` لوحة متابعة الباحثة.
- `js/data.js` محتوى الموديولات. `js/config.js` الإعدادات. `js/store.js` حفظ التقدم والنشاط. `js/progress.js` تسلسل عناصر الموديول.
- `build.py` يعيد توليد صفحات HTML إذا عدّلت القالب.
- شعارا الجامعة والكلية يظهران في الصفحة الرئيسية فقط (`assets/img/zagazig-logo.png` و`assets/img/faculty-logo.png`).

## نمطا الخريطة الذهنية (المتغير التجريبي)
- `mindmap.html` خريطة شاملة: المركز ← الموديولات الثمانية ← مفاهيم كل موديول (23 مفهومًا تُقرأ من `data.js`).
- `MINDMAP_PATTERN` في `js/config.js`:
  - `"interactive"`: الضغط على المفهوم ينقل إلى شرحه مع زر «العودة إلى الخريطة الذهنية»، وتظهر ✓ على المفاهيم المنجزة و🔒 على التي لم تُفتح بعد.
  - `"static"`: عرض فقط، بلا روابط أو انتقال أو حركة.
- نسختان جاهزتان `elearning-interactive` و`elearning-static` تختلفان في هذا السطر فقط.

## التقدم المتسلسل
- ترتيب الموديول: الاختبار القبلي أولًا ← المبررات والأهداف ← المحتوى ← الاختبار البعدي (يُفتح بعد إنهاء كل العناصر).
- داخل الموديول: لا ينتقل التلميذ إلى عنصر حتى ينهي ما قبله، وعند الإنهاء يُفتح التالي تلقائيًا.
  - المبررات والأهداف والتمهيد والتعريف والخريطة: تكتمل بالعرض.
  - سؤال الاختبار: باختيار إجابة. الأمثلة: بكشف المثالين. النشاط: بحفظ إجابة مكتملة. التقويم الذاتي: بالإجابة عن كل العبارات والضغط على «تحقق».
- بين الموديولات: الموديول التالي يُفتح تلقائيًا عند إنهاء السابق (`SEQUENTIAL_MODULES`).
- شريط ونسبة إنجاز لكل موديول في صفحة الموديول وكروت المحتوى، ويستأنف التلميذ من حيث توقف.
- `ALLOW_RETAKE:false` يمنع إعادة الاختبار القبلي/البعدي (تُحفظ أول نتيجة). اجعله `true` للسماح بالإعادة مع حفظ كل المحاولات.

## لوحة متابعة الباحثة (`researcher.html`)
- جدول بكل التلاميذ: المجموعة، الأسلوب المعرفي، الإنجاز الكلي وإنجاز كل موديول، مجموع درجات القبلي والبعدي، آخر نشاط. مع بحث وتصفية بالمجموعة.
- تفاصيل كل تلميذ: التقدم والنتائج لكل موديول (العنصر الحالي، القبلي، البعدي، الفرق، زمن الدراسة)؛ إجابات الأنشطة والتقويم الذاتي وإجابات كل سؤال؛ سجل نشاط كامل بالتاريخ والوقت ومدة كل خطوة (فتح، إنهاء، إجابة، نتيجة، الانتقال من الخريطة الذهنية…).
- تصدير «النتائج» و«سجل النشاط» إلى ملفات CSV تفتح في Excel/SPSS.
- إضافة التلاميذ (الاسم، الكود، كلمة المرور، المجموعة، الأسلوب المعرفي)، وتعديل المجموعة والأسلوب، ومسح تقدم تلميذ (للتجربة قبل التطبيق).
- التلميذ لا يدخل إلا البيئة الخاصة بمجموعته.

## ربط Firebase (مطلوب لتتابع الباحثة كل التلاميذ من أي جهاز)
بدون إعدادات Firebase تعمل البيئة في «وضع محلي» للتجربة فقط (البيانات على نفس الجهاز).
1. من console.firebase.google.com افتحي مشروعًا (الخطة المجانية Spark تكفي).
2. Authentication ← Sign-in method ← فعّلي **Email/Password**.
3. Firestore Database ← Create database، ثم من تبويب **Rules** الصقي محتوى `firestore.rules` واضغطي Publish.
4. Project settings ← Your apps ← Web app ← انسخي `firebaseConfig` وضعيه في `FIREBASE` داخل `js/config.js` **في النسختين**، مثل:
   `FIREBASE:{apiKey:"…",authDomain:"…",projectId:"…",storageBucket:"…",messagingSenderId:"…",appId:"…"}`
5. حساب الباحثة: Authentication ← Users ← Add user (بريدك وكلمة مرور)، وانسخي الـ UID. ثم Firestore ← Start collection باسم `admins` ← Document ID = الـ UID ← حقل `name` باسمك.
6. ادخلي `researcher.html` وأضيفي التلاميذ (الكود حروف إنجليزية/أرقام، وكلمة المرور 6 على الأقل)، وأعطي كل تلميذ الكود وكلمة المرور ورابط نسخة مجموعته.
7. النشر (GitHub Pages أو Firebase Hosting): ضعي كل نسخة في مجلد مستقل، وأضيفي نطاق الموقع في Authentication ← Settings ← Authorized domains.

ملاحظات:
- النسختان تستخدمان مشروع Firebase واحدًا، فتظهر المجموعتان في لوحة واحدة.
- لا تُخزَّن كلمات المرور في الشيفرة أو في Firestore؛ تديرها Firebase Authentication. لتغيير كلمة مرور تلميذ أو حذف حسابه استخدمي Authentication ← Users.
- يُحفظ فقط: الاسم والكود والمجموعة والأسلوب المعرفي والتقدم والإجابات وسجل النشاط. احصلي على موافقة أولياء الأمور وفق إجراءات أخلاقيات البحث قبل التطبيق.
- يعمل الحفظ مع انقطاع الإنترنت المؤقت ويُرفع عند عودة الاتصال.

## قفل الموديولات بكلمة مرور (اختياري)
`MODULE_PASSWORDS:true` يضيف قفلًا بكلمة مرور فوق التسلسل التلقائي، ويتطلب خدمة تحقق `ACCESS_ENDPOINT` (Cloud Function، تحتاج خطة Blaze). مغلق افتراضيًا.

ضع عنوان خدمة الاستقبال في `CONTACT_ENDPOINT`.
